# Log Visualization Feature for Administrators

## Overview
This feature provides administrators with a web-based interface to view, manage, and analyze system logs generated by the application.

## Components

### Backend (API)
- **Location**: `src/AppForSEII2526.API/Controllers/LogsController.cs`
- **Authentication**: Requires `Admin` role
- **Logging Provider**: Serilog with file-based sink

#### Endpoints
1. **GET /api/Logs/files**
   - Returns a list of available log files
   - Response: `200 OK` with array of file names

2. **GET /api/Logs/content?fileName={name}&lines={count}**
   - Returns the content of a specific log file
   - Parameters:
     - `fileName` (required): Name of the log file
     - `lines` (optional): Number of lines to return from the end of the file (default: all)
   - Response: `200 OK` with log content as string

3. **DELETE /api/Logs/{fileName}**
   - Deletes a specific log file
   - Response: `200 OK` on success

### Frontend (Web)
- **Location**: `src/AppForSEII2526.Web/Components/Pages/Logs.razor`
- **Route**: `/admin/logs`
- **Authentication**: Requires `Admin` role

#### Features
- View list of available log files
- Select and view log file contents
- Configure number of lines to display
- Refresh log file list
- Delete old log files
- Real-time error handling and feedback

### Log Configuration
- **Log Directory**: `logs/` (relative to API root)
- **File Pattern**: `api-log-YYYYMMDD.txt`
- **Rolling Interval**: Daily
- **Retention**: 30 days
- **Format**: `{Timestamp:yyyy-MM-dd HH:mm:ss.fff zzz} [{Level:u3}] {Message:lj}{NewLine}{Exception}`

## Security Features

### Authorization
- All endpoints require authenticated users with the `Admin` role
- Unauthorized access returns `401 Unauthorized`
- Forbidden access returns `403 Forbidden`

### Input Validation
The implementation includes multiple layers of validation:

1. **Path Traversal Prevention**
   - Rejects file names containing `..`, `/`, or `\`
   - Ensures files can only be accessed from the logs directory

2. **Log Forging Prevention**
   - Validates file names to reject newline characters (`\n`, `\r`)
   - Prevents injection of fake log entries

3. **XSS Prevention**
   - HTML-encodes file names before display in the UI
   - Prevents cross-site scripting attacks via malicious file names

4. **Parameterized Logging**
   - Uses Serilog's structured logging with parameters
   - Prevents log injection attacks

## Usage

### For Administrators

1. **Access the Logs Page**
   - Log in with an Admin account
   - Navigate to "System Logs" from the menu (only visible to Admins)

2. **View Logs**
   - Select a log file from the list on the left
   - Adjust the number of lines to display (0 = all lines)
   - Click "Load" to view the content

3. **Refresh Log List**
   - Click the "Refresh" button to reload the list of available log files

4. **Delete Old Logs**
   - Select a log file
   - Click "Delete File"
   - Confirm the deletion

### For Developers

1. **Logging in Code**
   ```csharp
   // Inject ILogger<T> in your controller/service
   private readonly ILogger<MyController> _logger;
   
   // Log messages at different levels
   _logger.LogInformation("User {UserId} performed action {Action}", userId, action);
   _logger.LogWarning("Potential issue detected: {Issue}", issue);
   _logger.LogError(exception, "Error processing request");
   ```

2. **Configuration**
   - Logging configuration is in `appsettings.json`
   - Serilog configuration is in `Program.cs`
   - Adjust log levels in `appsettings.json` under the `Serilog` section

## Maintenance

### Log File Management
- Log files are automatically rotated daily
- Files older than 30 days are automatically deleted by Serilog
- Administrators can manually delete log files through the web interface

### Monitoring Log Size
- Each log file is limited to the daily rolling interval
- Monitor the `logs/` directory size periodically
- Adjust `retainedFileCountLimit` in `Program.cs` if needed

### Performance Considerations
- Loading large log files may impact performance
- Use the `lines` parameter to limit the number of lines returned
- Consider external log management tools for production environments with high volume
